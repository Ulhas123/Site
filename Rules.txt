# Webnovel Reader: Workspace Rules
Stack: Vite + React 19 + TypeScript (strict) + Tailwind v4 + Zustand + Lucide + react-router. No new runtime deps without asking.
1. Never hardcode colors/sizes/fonts in components. Use semantic tokens only (bg-page, bg-outer, bg-raised, border-line, text-ink, text-muted, accent, system).
2. Novel content is typed blocks, never parsed from strings.
3. All overlays use the shared Drawer/Modal primitives (focus trap, Esc, scroll lock, aria-modal).
4. Every control is keyboard reachable, has :focus-visible styling, and icon-only buttons have aria-labels.
5. Respect prefers-reduced-motion.
6. Stay inside the current prompt's scope. No drive-by refactors. Keep files under 250 lines.
7. Finish every task with: tsc + lint + build clean, then browser-check at 390x844, 768x1024, 1440x900, attach screenshots, and list any deviations honestly. Never claim "pixel-perfect" without a reference comparison.
8. Don't read or analyse plans that are not in this folder itself. Don't take reference from similar projects and their plans that are stored locally.
